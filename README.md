# ikpvk.github.io

Personal portfolio of Krishna Prasad V K, live at https://ikpvk.github.io/.

It is a single page of plain HTML, CSS and JavaScript with no build step, served by GitHub Pages from `main`. To preview it locally:

```sh
python3 -m http.server 8000   # then open http://localhost:8000
```

Credits: music is "rose water" by massobeats (see `audio/CREDITS.md`), the Flappy Bird easter egg is based on nebez/floppybird (Apache-2.0, `flappy/LICENSE`), weather data comes from [Open-Meteo](https://open-meteo.com), weather icons are from [Lucide](https://lucide.dev) (ISC), and the font is [JetBrains Mono](https://www.jetbrains.com/lp/mono/) (SIL OFL, `fonts/OFL.txt`).
